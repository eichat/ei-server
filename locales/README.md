# Переклади EION

**Ці файли згенеровані. Не правити їх руками.**

Джерело — `../locales-source.json`, де всі 21 переклад кожного ключа лежать
поруч. Після зміни джерела:

```
node tools/build-locales.js
```

Генератор заразом перевіряє те, що раніше звірялося вручну: чи є переклад у
кожній мові й чи збігаються плейсхолдери `{name}` з англійською. Якщо ні —
падає й нічого не пише.

Перевірити без запису: `node tools/build-locales.js --check`

## Чому роздача все одно по одному файлу на мову

Застосунок тягне переклади з GitHub при старті й бере **лише свою** мову
(~45 КБ). Один спільний файл означав би ~900 КБ на кожен запуск.

## Додати новий ключ

1. Дописати в `locales-source.json` → `strings` з усіма 21 мовами.
2. `node tools/build-locales.js`
3. Закомітити і джерело, і згенеровані файли — застосунок читає саме їх.
